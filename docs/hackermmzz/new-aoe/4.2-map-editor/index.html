地图编辑器

相关源文件

以下文件被用作生成本 wiki 页面时的上下文：

  • Editor.ui
  • MainWidget.cpp
  • MainWidget.h
  • map.njust

地图编辑器是一个集成式关卡设计工具，支持对游戏地图进行实时修改。它提供地形编辑、对象放置、AI 行为配置以及地图序列化功能。编辑器与游戏运行在同一个事件循环中，因此可以即时预览修改效果。

有关地图加载和地图数据结构的信息，请参见 地图结构。有关 AI 行为中使用的区域定义详情，请参见 区域管理系统。

概览与架构

地图编辑器嵌入在 MainWidget 中，而不是作为独立应用程序存在。它共享游戏的渲染管线和坐标系统，因此在编辑过程中能够提供即时的视觉反馈。

地形修改

地形编辑以鼠标位置为中心，对 3×3 的方块区域进行操作。系统会施加约束，防止出现无效的地形配置。

高度修改

graph TB
    Start["HigherLand(blockL, blockU, height)"]
    
    CheckLoop1["遍历 3×3 区域中的每个方块"]
    CheckNeighbor["遍历 5×5 区域中的每个邻居"]
    CheckConstraint["height > neighborHeight?<br/>或 height - neighborHeight > 1?"]
    Return["返回（无效）"]
    
    CheckOcean["检查是否会影响海洋<br/>(在 7×7 区域内)"]
    
    ModifyLoop["遍历 3×3 中的每个方块"]
    UpdateHeight["m_heightMap[i][j] = height<br/>cell.setMapHeight(height)<br/>cell.reset()"]
    
    GlobalUpdate["对所有方块：<br/>resetOffset()"]
    Regenerate["map->GenerateType()<br/>map->CalOffset()<br/>map->InitFaultHandle()"]
    
    UpdateShore["如果 affectsOcean：<br/>updateShoreArea()"]
    
    Start --> CheckLoop1
    CheckLoop1 --> CheckNeighbor
    CheckNeighbor --> CheckConstraint
    CheckConstraint -->|无效| Return
    CheckConstraint -->|有效| CheckOcean
    CheckOcean --> ModifyLoop
    ModifyLoop --> UpdateHeight
    UpdateHeight --> GlobalUpdate
    GlobalUpdate --> Regenerate
    Regenerate --> UpdateShore

高度修改函数会强制相邻方块之间的高度差不能超过 1 级。这可以防止视觉伪影，并保证地形过渡平滑。

来源： HigherLand/LowerLand 见 MainWidget.cpp881-1003

地形类型修改

函数 行号 操作 副作用

区域数据结构

每种区域类型都使用特定结构存储其几何数据：

区域类型 数据结构 关键字段
RectArea RectAreaData dr, ur（中心），w, h（尺寸），areaType
CircleArea CircleAreaData dr, ur（中心），rad（半径），areaType
LineArea LineAreaData data（点向量），areaType

areaType 字段用于区分巡逻区域（1）和移动限制区域（0）。该信息既会在游戏过程中使用，也会在导出地图时使用。

The Map Editor is an integrated level design tool that enables real-time modification of game maps. It provides terrain editing, object placement, AI behavior configuration, and map serialization capabilities. The editor operates within the same event loop as the game, allowing instant preview of changes.

For information about loading maps and map data structures, see Map Structure. For details on area definitions used in AI behavior, see Area Management System.

Overview and Architecture

The Map Editor is embedded into MainWidget rather than being a separate application. It shares the game's rendering pipeline and coordinate systems, enabling immediate visual feedback during editing.

    Editor -->|"setCurrentAreaType()<br/>setTargetUnits()"| Areas
    
    Player -->|"Adds to build[] or<br/>human[] lists"| Map
    Map -->|"Updates map_Object[][]<br/>spatial grid"| Map

When objects are created through the editor, they are added to the same data structures used during normal gameplay. This ensures that edited maps behave identically to programmatically generated content.

Sources: MainWidget.cpp1109-1260 for object creation flow

Map Regeneration

After terrain modifications, the map must regenerate its visual representation:

  1. GenerateType(): Recalculates terrain types based on height
  2. CalOffset(): Recomputes isometric rendering offsets
  3. InitFaultHandle(): Updates terrain transitions
  4. updateShoreArea(): Redraws beaches (when ocean is involved)

Sources: MainWidget.cpp934-1002 for regeneration calls

Debug and Feedback

The editor provides visual feedback through the debug text system:

  • Green text: Tool selection confirmations
  • Red text: Error messages (e.g., invalid placement)
  • Blue/Yellow text: Status confirmations
  • Cyan/Magenta text: Area processing details

All editor operations log their actions using call_debugText() with appropriate color coding.

Sources: MainWidget.cpp160-267 for debug output calls throughout UI handlers
